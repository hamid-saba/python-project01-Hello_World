# Python Tkinter Learning Project

This is a simple project built using **Python** and **Tkinter**, aimed at improving my skills in GUI development as part of my learning journey toward **robotic engineering**.

## 🚀 Goals

- Practice Python fundamentals through hands-on projects  
- Learn how to build desktop GUI applications using Tkinter  
- Strengthen coding discipline and problem-solving  

## 🛠️ Tech Used

- Python 3
- Tkinter (standard GUI library)

## 🤖 Why This Matters

As a future robotics engineer, it's essential to be comfortable building tools and interfaces. Tkinter helps bridge the gap between backend logic and user interaction, which is important when developing control panels, diagnostics interfaces, or simulation tools for robots.
